## 📁 Projets universitaires

### 🐱 Le Ronron Café *(L3 - Développement Web Backend)*
Site web dynamique pour un bar à chats fictif, développé en binôme.
- Architecture MVC stricte en PHP orienté objet
- Base de données MariaDB (7 tables : chats, réservations, carte, horaires…)
- Fonctionnalités : gestion des réservations, upload de photos, espace admin sécurisé par session
- Hébergé sur le serveur universitaire de Lyon 2
